## 📌 О проекте

Обработка графики и применение тяжелых фильтров может занимать длительное время, поэтому классический синхронный веб-сервер не должен блокироваться в ожидании завершения задачи.

**PixelQueue** — это распределенная система, построенная на принципах микросервисной архитектуры с очередями сообщений, фоновой обработкой и real-time уведомлениями. Пользователь загружает изображение и выбирает нужный фильтр, `WebAPI` мгновенно принимает запрос и передает задачу в `RabbitMQ`, отдельный `Worker` выполняет фильтрацию в фоне, а сервис `SignalR` присылает push-уведомление о готовности результата. 🎨✨

## ✨ Основные возможности

Для обеспечения высокой производительности и отказоустойчивости в проекте реализован следующий функционал:

* 🎨 **Набор графических фильтров:** Обработка изображений в четырех режимах — негатив, отзеркаливание, размытие и повышение резкости.
* ⚡ **Асинхронная очередь задач:** Мгновенный отклик API за счет делегирования ресурсоемких операций фоновым воркерам через брокер сообщений `RabbitMQ` и `MassTransit`.
* 🔔 **Real-Time уведомления:** Мгновенная доставка статуса задачи (`done` или `failed`) клиенту в браузер через веб-сокеты `SignalR`.
* 🛡️ **Гарантия доставки и отказоустойчивость:** Поддержка повторных попыток (`retry`), очередей недоставленных сообщений (`DLQ` / poison-сообщения) и механизма `lease`-блокировок — если `Worker` упадет в процессе работы, зависшая задача автоматически вернется в очередь.
* 🔐 **Безопасность:** Аутентификация и авторизация по `JWT`-токенам, строгая валидация входных данных и централизованный глобальный middleware для перехвата ошибок.
* 📊 **Полная наблюдаемость (Observability):** Сбор структурированных логов в `ELK`, метрик в `Prometheus` и распределенная трассировка запросов через `OpenTelemetry` и `Jaeger`.

## 🏗 Архитектура и сценарий работы

Сервисы общаются асинхронно через **RabbitMQ**, а состояние задач, пользователей и метаданных хранится в реляционной базе данных **PostgreSQL**.

```text
[Клиент (SPA)] ──(REST + JWT)──> [WebAPI] ──(TaskCreated)──> [RabbitMQ / MassTransit]
      ^                             │                                   │
      │                             ▼                                   ▼
(Push: Готово!)               [PostgreSQL] <──(Сохранение)──── [Worker (Фильтры)]
      │                                                                 │
  [SignalR] <────────────(TaskCompleted / TaskFailed)───────────────────┘
